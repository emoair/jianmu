# Post-V1.0 Development Baseline

Active development starts from the V1.0 source review candidate. The v0.9.x sequence is preserved as an evidence archive rather than copied forward blindly.

New work should begin from `active_core` and `active_frontier` manifests. Legacy experiments should be referenced through archive indexes and reviewed before reuse. Every new capability needs a claim-boundary and not-proven registry update. Compiler validation remains the final engineering verifier.

This baseline does not change production boundaries, enable real promotion, or create an official release.
