# v1.0.8.5 Weak Signal Plan

v1.0.8.5 validates RedQueen governance response to controlled synthetic weak signals while preserving the staged opt-in profile and the real compile lane.

Implementation scope:

- add a shadow weak-signal lane
- reuse RedQueen plan execution
- reuse lifecycle guard behavior

- generate per-cycle records and audits
- keep production support, official release, and autonomous governance completion false

This plan does not introduce a natural-language layer, new C capability boundary, model training, default profile change, real promotion, or production release.
