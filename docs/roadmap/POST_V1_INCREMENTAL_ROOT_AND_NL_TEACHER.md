# Post-v1 Incremental Root and NL Teacher Direction

This note records future directions only. It is not implemented in v0.9.6.

- Root similarity incremental training: low similarity may create a new root,
  while high similarity may create a child or sub-root under an existing root.
- Verified backend as teacher: compiler-verified execution can later supervise
  an NL-to-semantic-IR adapter.

These are roadmap ideas, not current architecture changes or capability claims.
