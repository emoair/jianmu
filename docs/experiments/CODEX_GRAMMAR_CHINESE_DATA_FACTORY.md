# v0.9.15.2 Codex Grammar Chinese Data Factory

## Why v0.9.15.2 exists

v0.9.15 showed that cheap raw LLM free generation had extreme duplication and leakage risk. v0.9.15.1 could not run the multi-agent re-audit because the required raw input directory was missing. The raw route also exposed a language-domain issue: many draft samples were English, while JianMu's current supported input domain is Chinese.

## Language-domain correction

Current-supported training inputs are Chinese only. English is not current-supported. English and mixed-language samples are boundary, hard-OOD, future multilingual, or review cases and must not be counted as positive training examples.

## Data factory approach

Program structure is produced by deterministic grammar. Chinese natural-language descriptions are generated by template composition. Expected output is validated after generation through evaluator/compiler paths, and the compiler/evaluator is the final judge.

## Non-claims

This version does not claim Turing completeness, solved program synthesis, production readiness, or active LLM generation success.
