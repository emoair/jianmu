# v1.1-alpha LinguaForge NL to Mirror/StandardToken Alpha

## Why v1.1-alpha exists

V1.0 froze the bounded substrate and preserved the active core/frontier evidence. v1.1-alpha starts a narrow natural-language adapter probe without changing that substrate. The goal is Chinese NL to StandardToken / MirrorToken, then the existing token-to-IR and compiler/watchdog path.

## Scope

LinguaForge maps structured Chinese task descriptions to StandardToken and MirrorToken. It does not directly generate C, does not directly generate target_ir, and does not bypass the token layer.

## Evaluation

The alpha probe audits token schema, NL-to-token success, token-to-IR roundtrip, compiler-backed validation, paraphrase generalization, comfort-zone collapse, RedQueen NL assignments, and V1.0 substrate lock evidence.

## Non-Claims

- no natural language layer completed
- no general natural language understanding
- no production NL interface
- no solved program synthesis
- no formal Turing completeness proof
