# RedQueen Autopsy + Causal Forge

## Why v0.9.19 Exists

v0.9.17 showed that RedQueen Curriculum plus HydraBudget improved bounded-control performance, but RedQueen may still be a rule-shaped remedial curriculum generator. v0.9.19 decomposes which data-need specs and adversarial patterns plausibly contributed to the gain before scaling RedQueen further.

## RedQueen Autopsy

This version reports diagnostic spec-level attribution, pattern-level ROI, failure-mode mapping, template-overfit risk, and pseudo-diversity risk. Attribution is marked as measured, estimated, or diagnostic-only where appropriate; it is not presented as a new capability result.

## Causal Forge

Causal Forge upgrades the next curriculum design from "patch the weak stage" to "patch the causal reason for weakness." The next plan emphasizes contrastive pairs, minimal semantic differences, update-order contrasts, boundary-preserving negatives, and explicit safety gates.

## Regression Sentinel

This version uses Regression Sentinel, Capability Balance Gate, and Boundary Preservation Set terminology. It does not frame JianMu as a pure Transformer system and does not use a traditional replay-buffer framing. The sentinel checks old strong stages, boundary behavior, future-domain isolation, English/mixed-language boundaries, and function/array/recursion isolation.

## Non-Claims

v0.9.19 adds no new capability, does not claim Turing completeness, does not claim function/array production support, does not change the default profile, and does not enable real promotion.
