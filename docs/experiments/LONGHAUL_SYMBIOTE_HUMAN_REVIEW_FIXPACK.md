# Longhaul Symbiote Human Review Fixpack

## Why v0.9.25 exists

v0.9.24 produced a V1.0 freeze-candidate audit. v0.9.25 adds a longhaul Symbiote stability test and a machine-assisted pre-human-review fixpack. It is not a V1.0 release, not production promotion, and not human review completion.

## Longhaul test design

The longhaul diagnostic reports rolling windows rather than cherry-picking a single best result. It records best, final, mean, median, worst, and last stable windows; checks plateau behavior; audits comfort-zone collapse; verifies heldout generalization; and scales compiler validation evidence.

## Human-review fixpack

The fixpack prepares README wording review notes, claim wording guidance, not-proven notices, risk wording, human review checklist v2, large-file hygiene, and RC1 preparation notes. These are machine-assisted artifacts for later human review.

## Non-claims

This version does not claim production readiness, Turing completeness, solved program synthesis, natural language layer completion, real promotion, default profile change, or a release.
