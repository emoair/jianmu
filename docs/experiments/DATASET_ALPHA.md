# Dataset Alpha

The v0.5.6 dataset alpha creates a controlled Chinese intent-to-structure
benchmark seed before any learned-router or prefix-evolution training claims are
made.

The training target is not C source text. Each sample maps Chinese-first input
to structured labels:

- intent
- `route_id`
- AtomicExpert sequence
- ProgramIR token sequence
- slots
- trusted `expected_output`

Ground truth is generated by explicit dataset rules. JianMu runtime output and
generated C program output are not used to infer `expected_output`.

This dataset is intended for future v0.6 comparisons among:

- handcrafted router baselines
- prefix-evolution free generation
- cold-start evolution
- tiny learned intent routers
- execution-feedback correction

It is a controlled benchmark seed, not a general NLP benchmark and not evidence
of learned routing by itself.
