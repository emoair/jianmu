# CSystems Frontier Contract

CSystems frontier samples are controlled single-file or multi-file C subset projects with explicit system feature, memory, file IO, and build contracts.

Samples may include pointer basics, malloc/free lifecycle, sandboxed file IO, multi-file compile/link, and simple structs. They must not claim arbitrary project parsing or production support.

Tokens must not contain raw C source, raw target IR JSON, or expected output.
