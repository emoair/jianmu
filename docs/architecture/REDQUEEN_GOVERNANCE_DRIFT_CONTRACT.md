# RedQueen Governance Drift Contract

Governance drift is any movement outside the approved controlled opt-in boundary.

Forbidden drift includes:

- default profile modification
- real promotion enablement
- user-facing production enablement
- official release enablement
- production support flag changes
- unsupported dangerous compile attempts
- direct template path use
- marker IR direct compile
- summary-only validation
- external API calls
- model training or weight updates

Any drift blocks a positive v1.0.8.3 readiness result.
