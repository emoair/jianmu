# V1.0 Freeze Scope

This document defines what v0.9.24 prepares for human review as a V1.0 substrate freeze candidate.

Freeze candidate scope:

- Architecture Charter and Boundary-as-Data-Contract.
- Current supported bounded substrate boundary.
- Dataset schema contracts and leakage audit expectations.
- MirrorToken and Project StandardToken teacher schemas as offline/teacher artifacts.
- RedQueen v2 curriculum and required-feature scheduling policy.
- HydraBudget as shadow budget allocation only.
- CodeCartographer supported-subset module-to-StandardToken path.
- Symbiote freeze-thaw co-training protocol.
- IronJudge / real MSVC compiler validation protocol.
- Records, readiness, risk, and not-proven registry format.

Out of freeze scope:

- Real promotion.
- Production default runtime profile changes.
- Function, array, recursion, pointer, IO, or system-call production capability.
- Arbitrary project parsing.
- Natural language layer completion.
- Turing completeness, solved program synthesis, production readiness, and emergence claims.
