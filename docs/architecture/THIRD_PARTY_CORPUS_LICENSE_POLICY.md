# Third-Party Corpus License Policy

Allowed manual drop-in licenses:

- MIT
- Apache-2.0
- BSD-2-Clause
- BSD-3-Clause
- ISC
- CC0
- Unlicense

Quarantined by default:

- GPL
- LGPL
- AGPL
- unknown
- proprietary
- no license

This repository must not automatically fetch unknown-license GitHub code into redistributable training corpora.
