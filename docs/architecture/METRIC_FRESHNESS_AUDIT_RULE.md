# Metric Freshness Audit Rule

v1.0.3.1 metrics must be generated by the current probe records. Copying v1.0.2, v1.0.3, or summary-only metrics blocks positive claims.

The audit records a unique run id, source paths, copied-metric flags, fixed-metric flags, summary-only flags, and periodic-rule flags. If any freshness blocker is detected, readiness must be downgraded.

Syntax frontend counts are kept separate from correctness metrics.
