# Coverage Expansion Contract

v1.0.7.2 may expand only surface and bounded structural shape dimensions already represented by the experimental active bridge.

Allowed dimensions include function naming, parameter counts up to three, local precompute, bounded arithmetic expression variation, array lengths 1..32, fixed array aggregate variants, function-array aggregate variants using already supported array parameter syntax, and bounded structural recursion variants.

Forbidden dimensions include malloc, free, pointer-heavy programs, file IO, multi-file programs, arbitrary user code, natural language, unbounded recursion, mutual recursion, default production support, and real promotion.

Coverage success requires at least 12,000 unique compile units and 12,000 unique source hashes, while keeping all categories represented and avoiding category or policy skew above 40 percent.
