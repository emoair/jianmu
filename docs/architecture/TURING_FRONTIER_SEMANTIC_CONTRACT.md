# Turing Frontier Semantic Contract

Unbounded while, recursion, counter-machine state, WHILE-language constructs, and state growth are experimental frontier features. They are represented as semantic frontier tokens and support_status values, not as current_supported production capability.

Validation may use watchdog limits, max steps, max runtime, deterministic timeout classification, trace truncation, and compiler checks for terminating_known samples. This validation is finite evidence and must not be written as a mathematical proof of Turing completeness.

Unsupported, timeout_unknown, and nonterminating_observed samples must not carry fake expected_output values. Pointer, IO, system calls, dynamic allocation, and production recursion support remain outside the current supported boundary.
