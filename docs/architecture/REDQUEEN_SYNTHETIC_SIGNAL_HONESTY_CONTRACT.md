# RedQueen Synthetic Signal Honesty Contract

Synthetic signals must be marked as synthetic at design, scenario, cycle, summary, and readiness levels.

The audit must fail if a synthetic signal is claimed as a real compiler failure, claimed as a real capability fix, counted into real compiler correctness, or used to advance production support claims.

Passing this contract only supports `redqueen_controlled_weak_signal_response_positive`; it does not support production readiness or autonomous governance completion.
