# Requirement-Driven Code Variant Policy

Every generated variant must carry an explicit requirement spec. The spec documents mutation policies for variable renaming, function renaming, constant mutation, array size, loop direction, boundary values, sorting order, helper split, recursion base-case style, matrix dimensions, stack and queue capacity, and output format.

Requirement following is audited as diagnostic evidence. It is not a claim that JianMu can perform unrestricted source-to-source program transformation.

External code import is disabled unless a separate license audit verifies permissive metadata before use.
